# Student Management System

## 📌 Project Overview

The Student Management System is a Python-based application developed to manage student records efficiently.

The system allows users to add, view, search, update, and delete student information. Student data is stored in a JSON file so that records remain available even after the program is closed.

## 🚀 Features

- Add Student
- View All Students
- Search Student by ID or Name
- Update Student Information
- Delete Student
- JSON File Storage
- Exception Handling
- Input Validation
- Duplicate Student ID Prevention
- Email Validation
- Marks Validation
- Object-Oriented Programming
- Modular Programming

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling
